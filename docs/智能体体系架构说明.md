# 「一人 + Agent」智能体体系架构说明

**汇报人**：Platform Platform Admin
**日期**：2026-10-08
**密级**：内部

---

## 一、背景与目标

公司业务以项目制为主，各环节高度依赖人工经验。我们的目标是：**一人 + Agent 完成一整套业务工作流**——把部门业务经验固化为可复用、可管理的数字资产，使单个员工在 Agent 辅助下具备完成全流程的产能。

按照公司《关于智能体开发验收的通知》（2026-09-29），每个部门须于 **10 月 15 日**前至少配置 **2 个智能体**：以部门核心业务逻辑为核心、配置专属知识库、调度多个技能、可交付他人使用的 AI 应用系统。

以可研报告编制为例：员工对 Agent 说"编制 XX 项目可研报告" → 命中「可研报告编制智能体」→ 按内置业务 SOP 逐环节分派功能技能（总论、市场分析、财务测算……）→ 各技能执行中自动查部门知识库取模板、案例、数据 → 产物汇回智能体组装成完整报告。员工只在关键节点确认，不再逐环节手工操作。

## 二、总体架构

| 层 | 建设主体 | 职责 |
|----|----------|------|
| 宿主层（Agent 运行环境） | 公司统一选型（当前 WorkBuddy） | 仅提供运行环境，不承载业务资产 |
| **Org AI 能力网关**（MCP 服务层） | Platform（已建成） | 技能与知识库的**统一服务出口**：技能分发/版本管理、知识库检索（关键词+语义）、专家、数据工具 |
| 智能体（主编排技能） | 各业务部门 | 承载部门业务全流程 SOP，任务分派与产物收口 |
| 功能技能 | 各业务部门 | 完成具体章节/子任务/通用工具职能 |
| 部门知识库 | 各业务部门（系统由公司统一建设） | 部门知识的存放、更新与被检索 |

## 三、核心设计原则

**1. Agent 无关（最重要的设计决策）**。所有技能与知识库不绑定任何 Agent 产品，经公司自建的Org AI 能力网关统一分发和服务，任何支持 MCP 协议的主流 Agent 均可直接接入。当前宿主为 WorkBuddy；未来更换 Agent 工具时**业务资产零迁移、零重写**，只换宿主——公司在 AI 工具选型上始终掌握主动权，不受制于任何外部产品。

**2. 部门自治**。业务怎么拆、SOP 怎么设计，由最懂业务的部门自己定；公司只统一规范（命名、结构、接口、质量红线），不干预业务内容。

**3. 统一分发、集中管控**。所有技能入技能管理系统，统一版本、统一测试、统一下发；使用情况可查、可管、可回收，全部操作有审计。

## 四、建设现状（截至 2026-10-08，平台侧已全部建成）

| 建设项 | 状态 | 说明 |
|--------|------|------|
| SkillHarbor 统一工作站（门户） | ✅ 上线 | 账号唯一源（全员一套密码）、工作台集成知识库与工具管理 |
| Org AI 能力网关 | ✅ 上线 | 16 个 MCP 工具在线：技能 6 个 + 知识库 4 个（含语义检索）+ 专家/数据/统计 |
| 部门知识库（15 库） | ✅ 上线 | 八大目录框架就位、全员只读开放、部门维护人可写；**语义检索**（Word/Excel/PDF 正文可被人话搜到） |
| 技能管理与审核发布 | ✅ 上线 | 上传→审核→上架→统计闭环 |
| 运维保障 | ✅ 在位 | 每日备份（恢复演练已通过）、监控告警、操作审计 |

**平台侧无欠账，当前瓶颈只在各部门的内容与技能交付**——这正是 10 月 15 日验收要解决的问题。

## 五、部门职责（三件事）

| # | 任务 | 交付标准 |
|---|------|----------|
| 1 | 开发本部门 2 个智能体 + 功能技能套件 | 按《智能体技能开发指南》：业务 SOP、任务映射、知识库依赖声明、闸口与红线；通过测试后发布 |
| 2 | 建设并持续维护部门知识库 | 按统一框架完成 P0 内容入库（模板×2 套/方法×2 份/案例×4-6 个），指定知识库责任人 |
| 3 | 指定专人持续迭代 | 每部门 1 名技能开发责任人 + 1 名知识库责任人，按变更流程持续迭代 |

**推进方式**：已按"7-8 天完成一个部门首期交付"设计了标准化推进节奏（准备/建库/开发/发布四阶段，建库与开发并行），并由Platform提供全套指南文档与答疑支持。

## 六、下一步计划

1. **10 月 15 日集中验收**：各部门 2 个智能体 + 知识库 P0 内容交付；
2. **试点样板**：优先支持 1 个部门跑通"智能体 + 知识库"完整闭环（建议可研报告编制业务），形成样板降低其他部门跟进成本；
3. **验收后推广**：技能跨部门复用（工具型技能注册为公司级 MCP 工具）、知识库内容持续沉淀、使用数据纳入运营分析。

---

*附：与既有工作的关系——本体系与全员 AI Agent 培训互为支撑（培训解决"会用"，智能体体系解决"用出产能"）；知识库系统、技能管理系统、AI 能力网关均由Platform统一建成，各部门无需承担系统开发，只负责业务内容。*
