# 审核与发布说明

申请人通过“发布资源”直接进入完整表单。选择资源类型、上传项目后，平台自动整理用途、功能与结构；有歧义时在原窗口回答业务问题，缺少必要功能时按修改建议补齐后重传。提交后进入管理员审核，进度可在“我的资源”或上传记录查看。

## 申请人如何发布

1. 选择智能体、AI 技能或工具；工具另选网页、客户端、服务或链接。上传包会按实际内容检查，所选分类与包内容不一致时明确提醒并调整分类，请核对是否传了正确的包。
2. 在同一窗口查看“包内容解析”，核对右侧名称、描述、分类、适用部门和业务标签。系统自动填入的信息可以修改；本人已有资源的名称由绑定对象确定。
3. 更新已有资源时，确认要更新的对象并填写更新说明。切换新建或更新对象会重新核对，解析中不能提交。
4. 可以先保存草稿，再从上传记录继续。解析失败或草稿发生冲突时，点击“重新解析”同步最新版本，核对后再次提交；系统保留当前填写内容，不自动重复旧提交。

发布窗口尺寸固定，两栏内容分别滚动，关闭、保存和提交按钮保持稳定。页面只有这一个发布入口；结构维护仍可在包检查结果下展开。

## 管理员如何审核

1. 在“审核中心”选择智能体、AI 技能或工具队列，点击对应记录的审核入口。
2. 先核对用途、包含功能与执行步骤，再查看当前核查结果。需要了解原始解析、入口路径或类型维护时，展开技术信息。
3. 更新提交同时核对绑定的线上对象、当前版本与本次变化，并参考申请人填写的更新说明。变化比较覆盖用途、功能、依赖、步骤和展示设置，不表示已经审阅所有正文或程序代码。
4. 信息确认后点击通过；发现内容不符时选择驳回原因并补充说明。驳回更新不会改变当前线上版本。

审核详情保持固定尺寸，长内容在窗口内部滚动；顶部关闭和底部操作保持稳定。

## 如何理解当前核查

| 状态 | 含义与处理 |
|---|---|
| 核查完成 | 当前可检查的材料与必要关系已核对，继续判断业务内容是否合适 |
| 有提醒项 | 阅读具体提醒，再决定通过或驳回 |
| 存在阻断项 | 必要功能、文件或结构存在问题，补齐后再发布 |
| 暂无法核实 | 材料过期、历史信息不全或服务暂不可用；重新核查，仍无法确认时让申请人补充材料 |

技能与智能体会检查当前包及平台依赖；工具会核对材料是否存在并展示提交检查，平台不会在审核核查中运行工具或探测外部链接。核查完成也不能替代审核人对用途、描述和实际效果的判断。

## 运行环境要求

有些技能需要 AI 助手提供文件展示、联网检索或其他接口。平台会把识别出的要求整理到上传结果、审核详情和发布后的资源详情中，使用前需确认自己的环境具备这些能力。

只有运行环境无法核实时，可以带提醒发布，无需额外勾选或配置；这不表示平台已验证接口可用。明确缺少包内文件、引用的子技能不存在或已停用，仍会阻止发布，不能用环境声明代替补齐。

这些要求随发布版本保存，更新审核也会显示变化。历史包没有声明时不会凭空补写，必要时由作者更新项目。

要求较多时，可在清单内部滚动查看，不影响顶部关闭和底部操作。

## 冲突、失败和驳回

核查期间若项目内容或状态变化，操作会提示重新核查。查看新结果后，再由审核人点击通过或驳回；系统不会替你自动重复旧决定。

请求失败会保留填写内容，可检查连接后重试。处理过程中按钮暂时锁定，避免重复操作。待审核和部署失败记录都可以驳回，原文件保留供申请人继续修改；其他状态不能直接驳回。
