# 知识库使用说明

**版本**：v2.0（2026-10-08）
**发布**：Platform Platform Admin
**适用对象**：全体员工（读取）；各部门负责人与知识库责任人（维护）

---

## 一、知识库是什么

公司知识库由 **14 个部门库**组成（每部门一个，含董事会与投资部），按统一框架组织，是智能体与全员检索的**统一知识底座**——模板、方法论、案例、政策等不再散落个人电脑。

**八大目录**（全公司统一，一级目录不得增删改名）：

| 目录 | 放什么 | 首批优先级 |
|------|--------|-----------|
| 01-模板库 | 报告模板、章节模板 | P0（2 条业务线各 1 套） |
| 02-方法论库 | 编制指南、分析方法说明 | P0（每业务线 1 份） |
| 03-案例库 | 过往项目成果（脱敏），按业务线建子目录 | P0（每业务线 2-3 个） |
| 04-政策法规库 | 政策文件、法规、规划文本（按国家/省/市） | P1 |
| 05-数据资料库 | 行业数据、区域经济数据（按行业/区域） | P1 |
| 06-标准规范库 | 国标行标、收费标准、合同范本 | P1 |
| 07-术语口径库 | 统一术语表、数据口径定义 | P2 |
| 99-归档区 | 过期/被替代资料（只进不删） | — |

二级及以下目录由部门按业务自定。

## 二、权限模型（谁 能做什么）

| 人员 | 权限 |
|------|------|
| **全体员工** | 登录 SkillHarbor 门户即可**浏览全部 15 库**：查看、搜索、在线预览、下载（无需申请） |
| **部门负责人及指定维护人**（每部门 ≤2 名） | 另有**本部门库写权限**：上传、新建、重命名、移动、删除 |

写权限由Platform按白名单开通（部门提出，SkillHarbor 账号体系内管理，密码与门户同一套）。所有操作有审计记录（谁、何时、对哪个文件做了什么）。

## 三、人怎么用（SkillHarbor 门户 → 工作台 → 知识库）

| 操作                   | 说明                                                                                            |
| -------------------- | --------------------------------------------------------------------------------------------- |
| **浏览**               | 仓库卡片进入 → 左侧目录导航 + 面包屑；跨部门库直接点开即可看                                                             |
| **搜索**               | 顶栏搜索框，**关键词 + 语义双路检索**——可以用人话问："园区项目收益怎么测算"能命中《财务评价测算口径说明》（不必记得文件名）；结果带语义命中标识与内容摘要，可"定位"到所在目录 |
| **在线预览**             | 点击文件名：Word/Excel/PPT/PDF 自动转 PDF 显示；md 显示富文本；图片直接查看                                           |
| **下载**               | 悬停文件行 → 下载按钮                                                                                  |
| **上传**（维护人）          | 工具栏"上传文件"，支持多选与百 MB 级大文件，带进度条                                                                 |
| **新建/改名/移动/删除**（维护人） | 悬停 ⋮ 菜单操作；删除有确认弹窗与 2 小时防误删锁                                                                   |
| **历史版本**             | ⋮ → 历史版本：每次覆盖上传自动存版，可看版本号/操作人/备注                                                              |

**修改文档的方式（统一"上传制"）**：平台不提供在线编辑——下载文件 → 本地编辑（保留 Office 原生排版与修订痕迹）→ **上传同名文件即为新版本**，历史版本自动保留。需要找回旧版本内容时，用本地存档重新上传即可。

## 四、AI 怎么用（WorkBuddy / 任何 MCP 客户端）

**前提：配置 MCP 连接器（一次性，一切 AI 工作的前提）**。登录 SkillHarbor 门户 → 首页「**AI 使用指引**」→ **下载一键配置脚本（.bat），双击运行一次**即自动完成（无需手动添加任何地址；浏览器提示安全警告时选「仍要运行」，已打开的 WorkBuddy 重启后生效）。连接成功后工具列表会出现技能与知识库工具（kb_search / kb_get 等）；已配置过的同事无需任何操作，新机器找不到身份时找Platform登记 IP→姓名映射。

配置完成后，在 WorkBuddy 中直接用自然语言即可触发知识库检索：


- "**查一下知识库里**光伏电站收益测算的口径"→ 自动调 `kb_search` 检索并给出带出处的结果；
- 智能体执行任务时会**按声明自动查本部门库**取模板/案例/数据（`dept` 参数已写死在技能里）；
- 需要正文时 AI 自动调 `kb_get` 取全文；产出物可经 `kb_upload` 归档回库。

检索由关键词与语义向量双路完成，Word/Excel/PPT 的**正文内容**也参与语义索引（长文档全覆盖）。个人使用量按 IP 实名计入统计。

## 五、内容维护规范（知识库责任人）

**1. 入库命名公式**（文件名是重要检索线索，同时语义索引已覆盖正文内容）：

```
{类别码}-{主题}-{限定词}-{年份}-v{版本}
```

类别码：M=模板、F=方法、C=案例、P=政策、D=数据、S=标准、T=术语。例：`M-可研报告模板-产业园区-2026-v2`。

**2. 更新——覆盖上传即存新版本**：直接上传**同名文件**，系统自动保存为新版本（历史版本可查可溯），无需手动归档旧版；仅当内容主题变化（不再属于该位置）时移入 99-归档区。

**3. 删除——归档优先**：原则上移入 99-归档区不删除；确需删除（错误上传、涉密文件等）由知识库责任人执行，系统自动保留 2 小时防误删锁，操作进入审计日志。

**4. 上传前查重**：同主题旧版本先归档再传新版，避免同名不同义混存。

**5. 季度清理**：每季度由知识库责任人检查归档区与失效内容。

**6. 内容质量**：案例须脱敏；政策注明时效；引用数据标来源；md/docx 优先（可被语义索引充分理解）。

## 六、常见问题

**Q：说"没权限"看不了某个库？** 读取全员开放，登录 SkillHarbor 即可看全部库；看不到写按钮是正常的——写权限限本部门维护人，找部门负责人或Platform申请。

**Q：搜不到刚上传的文件？** 语义索引在上传后自动更新（秒级）；若仍未命中，确认文件命名与内容是否包含相关表述，或换自然语言问法再试。

**Q：怎么改文档 / 找回旧版本？** 修改一律走"下载 → 本地编辑 → 上传同名新版本"；找回旧版：本地有存档直接重传，没有则联系Platform从版本库恢复。

**Q：误删了文件怎么办？** 2 小时内同名重传即可恢复位置；或联系Platform从版本历史找回。

**Q：跨部门想给别人写权限？** 跨部门默认只读；确有协作需要，由部门负责人向Platform提出单独授权。
